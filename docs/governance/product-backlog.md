# Product Backlog Classification

## MVP
- Solution architecture, DI, configuration, logging, error handling, SQLite initialization.
- Site management and encrypted credentials.
- WordPress connection testing and offline-first synchronization.
- Core Explorer, SEO Audit, Suggested Changes, Approval Queue, Execution Center.
- Backup/restore, settings, Arabic/English, light/dark mode.

## Version 1.0
- Full content/media/taxonomy sync.
- Content, SEO, links, visual, performance, and accessibility auditing.
- Multi-provider AI proposals and usage tracking.
- Safe execution adapters with backup, verification, evidence, retries, and rollback.
- Reports, logs, scheduler, notifications, health and transaction centers.
- Role-based security and release packaging.

## Post-launch
- Cloud team collaboration and shared approval queues.
- Competitor and keyword intelligence integrations.
- Advanced visual editing and generated media workflows.
- Plugin marketplace and external automation connectors.

## Classification rule
Every new feature must be assigned to MVP, Version 1.0, or Post-launch before implementation and must identify dependencies, risk, acceptance criteria, and verification evidence.
