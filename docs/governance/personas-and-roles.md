# المستخدمون المستهدفون والأدوار

## Administrator / المدير
- إدارة المستخدمين والأدوار والإعدادات والمواقع والنسخ الاحتياطية.
- اعتماد وتنفيذ واسترجاع كل أنواع التغييرات المدعومة.
- الوصول إلى السجلات والتقارير وأدوات التشخيص.

## Editor / المحرر
- مزامنة المحتوى وتشغيل الفحوصات وإنشاء المقترحات وتحريرها.
- إرسال التغييرات للمراجعة.
- لا ينفذ عمليات خطرة أو استعادة قواعد البيانات دون صلاحية.

## Reviewer / المراجع
- مراجعة Before/After والمخاطر والأدلة.
- قبول أو رفض أو تعديل الاقتراحات وإضافة ملاحظات القرار.
- لا يغير إعدادات النظام أو بيانات الاتصال.

## Operator / منفذ العمليات
- تشغيل خطط التنفيذ المعتمدة، متابعة التحقق، إعادة المحاولة، وفتح الأدلة.
- لا ينشئ اعتمادًا لنفسه عند تطبيق مبدأ فصل المهام.

## Auditor / المدقق
- وصول قراءة فقط إلى القرارات والتنفيذ والسجلات والتقارير والأدلة.

## Permission principles
- أقل صلاحية لازمة.
- فصل المراجعة عن التنفيذ للعمليات عالية الخطورة.
- كل قرار وتنفيذ واسترجاع مرتبط بالمستخدم والوقت وCorrelation ID.
