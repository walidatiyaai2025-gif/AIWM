# Part 66 Release Notes

- Sidebar navigation now behaves as an accordion: selecting a screen keeps only its parent group expanded and collapses the others.
- Dashboard selection collapses every navigation group.
- Added a complete Article Generator screen with content-plan selection, title, focus keyword, tone, language, meta description, local HTML preview, word count, copy, and clear commands.
- Article generation is preview-only and does not publish to WordPress.
- Updated the bundled user guide for Part 66.
