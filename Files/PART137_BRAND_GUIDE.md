# AI WordPress Management — Application Brand Guide

## Core colors

| Token | Hex | Usage |
|---|---:|---|
| Brand Teal | `#16B6A6` | Primary actions, progress, active states |
| Brand Mint | `#22D3B0` | Hover, automation, secondary highlights |
| Information Blue | `#3B82F6` | Information and diagnostics only |
| Deep Navy | `#0F172A` | Navigation, strong headings, branded surfaces |
| Slate | `#64748B` | Secondary text |
| Light Slate | `#E2E8F0` | borders, headers, separators |
| Canvas | `#F8FAFC` | application workspace |
| White | `#FFFFFF` | cards and content surfaces |

## UX rules

- One primary action per screen.
- Every long-running action uses the global locked loader.
- Every decision dialog uses the Office/Ribbon dialog system.
- Green means completed, amber means current/review, red means blocked/not started.
- The active site must stay visible throughout the guided journey.
- Advanced tools remain under their Ribbon groups; the Dashboard drives the normal user journey.
