# Part 133 — Executive Report Test Guide

1. Select a website.
2. Run an analysis and, ideally, one Safe Autopilot execution.
3. Open **SYSTEM > Reports**.
4. Confirm the current score, latest run, before/after score, and metrics are populated.
5. Click **Export HTML** and review the printable report.
6. Click **Export PDF**. The generated PDF should open automatically.
7. Confirm the report includes recent jobs and executed/failed AI changes.
8. Use **Open latest** and **Open exports** to verify file navigation.

Exports are stored under the application's Exports/ExecutiveReports directory.
