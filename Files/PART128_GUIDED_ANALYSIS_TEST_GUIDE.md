# Part 128 Test Guide

1. Select a website from **SITE & DATA → Sites**.
2. Return to **HOME → SEO Journey**.
3. Press **Start optimization**.
4. Confirm progress advances through five named stages.
5. Confirm SEO Score changes from `NOT ANALYZED` to a weighted baseline when local data exists.
6. Confirm the application opens **Suggested Changes** when analysis finishes.
7. Confirm no WordPress write appears in API Logs during this analysis-only workflow.
8. Press Start twice quickly and confirm duplicate execution is prevented by the disabled command.
