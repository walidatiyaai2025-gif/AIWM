# AI Autopilot Test Guide

1. Select a configured WordPress site.
2. Open AI & Automation > Autopilot.
3. Choose Monitor Only first and click Run full workflow.
4. Confirm all seven stages complete and no WordPress write occurs.
5. Choose Semi-Automatic. The workflow may approve and prepare low-risk supported actions, but it does not execute them.
6. Review Approval Queue and Execution Center.
7. Choose Fully Automatic only after Bridge diagnostics, AI Automation readiness, backups, screenshots, and verification are enabled.
8. Run the workflow and review SYSTEM > API Logs, Jobs, Execution Center evidence, and rollback state.
