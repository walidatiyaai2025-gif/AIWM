# Part 129 Test Guide

1. Start the app and select a website.
2. Open Dashboard -> SEO Journey.
3. Confirm the recommended action says **Start analysis** for a site with no baseline.
4. Run analysis and confirm the recommended action changes to **AI review**.
5. Confirm the projected score and estimated gain appear beside the current score.
6. Approve at least one concrete action and refresh Dashboard.
7. Confirm the recommended action advances to Execution Center.
8. Execute a supported action and verify it; refresh Dashboard.
9. Confirm the journey advances to Evidence and then History.
