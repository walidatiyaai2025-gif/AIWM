# Part 83 — AI Error Resolution, Automation Policy, Execution Evidence

- Every global application error now opens an AI diagnosis panel with an exact action, risk, and policy decision.
- Added AI Automation settings: ask/auto-low-risk/manual-only, auto-execute low-risk, auto-reject high-risk, before/after evidence, verified-result requirement, and splash minimum.
- Suggested Changes can automatically reject high-risk items and execute supported low-risk changes according to settings.
- Automated and direct changes capture before/after website screenshots through Visual Inspector when enabled.
- Splash remains visible for at least 3 seconds (configurable up to 30 seconds).
- High-risk, credential, destructive, and staging actions remain guarded and are never silently executed.
