# Part 47.1 — Execution Center Reliability and Button Contrast

- Execute and Rollback commands support the single selected row even when multi-select synchronization is empty.
- Added approval status and pending count to the queue.
- Improved primary/secondary/disabled button text contrast.
- Disabled buttons remain visibly disabled without becoming unreadable.
