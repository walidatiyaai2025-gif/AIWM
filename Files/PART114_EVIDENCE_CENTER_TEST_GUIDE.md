# Evidence Center test guide

1. Start the application and select a site.
2. Open **SYSTEM → Evidence**.
3. Click **Refresh**.
4. Confirm captured screenshots appear in the grid.
5. Search by site, folder, file name, `before`, or `after`.
6. Select an image and verify the preview and metadata.
7. When a matching pair exists, use **Before** and **After** to compare it.
8. Run a verified Visual Editor execution or Visual Inspector scan, return to Evidence Center, and refresh.
9. Confirm the new files are indexed without restarting the application.

The screen is read-only and safe to test on production data.
